The Workflow

7 steps from image to website

Each card shows what happens, who does it, and what happens next. That's all you need.

01Step
Image Enters
What Happens

A product image is added to the Media Library.

System identifies: filename, image type, product group, image view.

Who Does It

System automatically, or Admin / Employee uploads it.

What Happens Next

Image goes to Media Review to check if it belongs to the correct product.

NEXT → 02 Media Review
▼
02Step
Media Review
What Happens

The image is checked to make sure it belongs to the correct product.

Possible results: ✓ Correct · ⚠ Needs review · ✕ Wrong / duplicate

Who Does It

System flags it first, then Super Admin reviews it.

What Happens Next

If correct, the image is connected to its product.

NEXT → 03 Product Mapping
▼
03Step
Product Mapping
What Happens

The image is connected to the correct product. Front, side and back images belonging to the same product are grouped together.

Who Does It

System groups by filename, Admin confirms the mapping.

What Happens Next

A product draft is created with its images.

NEXT → 04 Product Created
▼
04Step
Product Created
What Happens

The product receives its product ID and product information.

Example: Product ID BAN-001, Name Women's Bangle, Price, Category, Images.

Who Does It

System creates the draft with a permanent ID.

What Happens Next

The draft goes to the assigned employee for completion.

NEXT → 05 Employee Review
▼
05Step
Employee Review
What Happens

The assigned employee checks and completes the product information. They can update allowed product details and submit the product for review.

Who Does It

Assigned Employee (only their products).

What Happens Next

Product is submitted to Super Admin for final approval.

NEXT → 06 Admin Approval
▼
06Step
Admin Approval
What Happens

The Super Admin checks the final product. Before publishing, required review issues must be resolved: Name, Price, Taxonomy, Grouping, Media.

Who Does It

Super Admin only.

What Happens Next

If everything is correct, product is approved and published.

NEXT → 07 Website
▼
07Step
Website
What Happens

Once approved and published, the product becomes visible to customers. It can appear in Explore, Category, Search, Product Page, Collections.

Who Does It

System automatically shows only published products.

What Happens Next

Customer can see and buy it. Journey complete.

Two Types of Images

Product media vs Marketing media

Both are images, but they are used in completely different places.

Product Media

Shows a real product

Belongs to exactly one product

  • Product card (the small tile in shop)
  • Product page gallery
  • Hover image (second view on mouse)
  • Front / Side / Back views

Sells a mood

Not linked to any product — linked to a place on site

  • Banner / Sale section

  • Lookbook / collection cover

PRODUCT IMAGE → PRODUCT. MARKETING IMAGE → HOMEPAGE / PROMOTION. One image can never be both.

Publishing Rules

Why can't some products be published?

A small checklist keeps bad products away from customers. If any item fails, admin cannot publish.

📝 Name

Product name needs review.

Example: name is still placeholder like “Uncatalogued Bangle · BAN-001”.

💰 Price

Product price needs review.

Example: price is 0 because system refused to guess it.

🏷️ Taxonomy

Category / classification needs review.

Example: category was guessed from filename, or subcategory missing.

🖼️ Grouping

Product images need grouping / identity review.

Example: system isn't sure if two photos show same product or two products.

People & System

Who does what?

Only three roles. No confusion.

⚙️

System

Automatic
  • Registers media — gives each image a permanent ID
  • Groups media based on filename rules
  • Maintains product / media relationships
  • Filters storefront to show only published products
👤

Employee

Works on assigned products
  • Completes product information (name, price, category, description)
  • Reviews product media — does the photo match?
  • Submits product for approval when ready
  • Can only edit products assigned to them
👑

Super Admin

Final control
  • Reviews submitted products
  • Resolves important issues (name, price, grouping)
  • Approves / publishes products
  • Manages employees and media ownership
When Things Go Wrong

What if something is wrong?

Every problem has one clear fix.

❌ Wrong image
→
Send to media review — admin decides if it belongs or not.
🧩 Wrong product mapping
→
Correct the mapping — re-assign image to right product.
📝 Missing product information
→
Employee completes it — name, price, category, description.
⚠️ Name / price / category problem
→
Resolve review flag — fix the data, flag clears automatically.
↩️ Product rejected
→
Goes back for correction — employee fixes it and submits again.
